# Helloworld Dataset Comparator

An utility web application for quick data reconciliation between 2 datasets.

## 🚀 App Demo


---


## Backend server

To start the backend development server, run:

```bash
cd backend && mvn spring-boot:start
```

## Frontend app

To serve the frontend development server, run:

```bash
cd frontend && ng serve --open --proxy-config proxy.conf.json
```
